# WHIP Protocol

The `WebRTC-HTTP` Ingestion Protocol (WHIP) is an open `IETF`-defined protocol that standardizes the signaling process for using WebRTC as a media ingest method in livestreaming services. It provides a simple, HTTP-based handshake between a media publisher and the server's ingestion endpoint. 
This allows broadcasting software to easily push a live `WebRTC` stream to a server using `HTTP` request-response exchange.
